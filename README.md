Dental Appointment Management System - Clínica Oral Care 🦷

Web system for managing dental appointments, developed as a Final Graduation Project (TCC) in the Software Engineering course.

📋 Features

✅ Patient Registration

📅 Appointment Scheduling with FullCalendar

🔄 Appointment Cancellation and Rescheduling

🦷 Procedure Recording by Dentist

🕒 Specialist Schedule Management

📧 Email Reminders (SendGrid)

📁 Patient History

🧾 Health Insurance Integration (informative field)

🔐 Login System with access control (patient, dentist, receptionist)

🛠️ Technologies Used

PHP 8.2

MySQL

Bootstrap 5

JavaScript

FullCalendar.js

SendGrid API (via cURL and PHP)

PHPMailer (optional)

⚙️ Installation

Clone the repository

git clone https://github.com/Hugopaulo1986/clinica-oral-care.git
cd clinica-oral-care


Install dependencies

composer install


Create the .env file based on .env.example

SENDGRID_API_KEY=YOUR_KEY_HERE
DB_HOST=localhost
DB_USER=root
DB_PASSWORD=
DB_DATABASE=teste_db


Set up your local environment

Use XAMPP or WAMP

Create the MySQL database and import the SQL script

Access in the browser

http://localhost/clinica-oral-care

🔒 Security

Uses session_start() for session control by user profile

Recommended use of password_hash() and password_verify() in login

SendGrid API key loaded via .env

config.php, .env and /logs/ are protected by .gitignore

Repository free of secrets (no keys in Git history)
